## 1. 메인 대시보드

### 1.1 화면 개요

**목적:** 전체 포트폴리오 상태를 한눈에 파악

**접근 경로:** 로그인 후 첫 화면

**주요 기능:**
- 실시간 손익 현황
- 보유 포지션 현황
- 오늘의 거래 내역
- 시장 지수
- 활성 전략 상태

---

### 1.2 레이아웃 구조

```
┌─────────────────────────────────────────────────────────────────┐
│ [상단 네비게이션 바]                                 [사용자 메뉴] │
├────────┬────────────────────────────────────────────────────────┤
│        │  [계좌 요약 카드]                                       │
│        ├─────────────────────────────────────────────────────────┤
│        │  [손익 차트]                        [시장 지수]          │
│        ├─────────────────────────────────────────────────────────┤
│  사이드 │  [보유 포지션 테이블]                                   │
│  바     ├─────────────────────────────────────────────────────────┤
│  메뉴   │  [오늘의 거래 내역]                [활성 전략]          │
│        └─────────────────────────────────────────────────────────┘
```

**그리드 구조:**
- 사이드바: 280px (고정)
- 메인 콘텐츠: `calc(100% - 280px)`
- 위젯: 12 컬럼 그리드 시스템

---

### 1.3 상단 네비게이션 바

**높이:** 64px

**구성 요소 (좌→우):**

```
[로고] [검색창]                          [알림] [설정] [사용자 아이콘]
```

#### 로고
- 크기: 160px × 32px
- 좌측 여백: 24px
- 클릭 시 대시보드로 이동

#### 검색창
- 너비: 400px
- Placeholder: "종목 검색 (종목명 또는 코드)"
- 아이콘: 돋보기 (좌측)
- 단축키: `Ctrl + K` 또는 `Cmd + K`

#### 우측 아이콘 그룹
- 간격: 16px
- 아이콘 크기: 24px
- **알림 아이콘:** 
  - Badge로 읽지 않은 알림 수 표시
  - 클릭 시 드롭다운 (320px × 480px)
- **설정 아이콘:**
  - 클릭 시 설정 페이지로 이동
- **사용자 아이콘:**
  - 클릭 시 드롭다운 (프로필, 로그아웃)

**배경:** White (라이트 모드), #1E1E1E (다크 모드)  
**하단 구분선:** 1px solid #E0E0E0

---

### 1.4 사이드바 메뉴

**너비:** 280px (확장), 72px (축소)  
**배경:** White (라이트), #1E1E1E (다크)

**메뉴 구조:**

```
📊 대시보드            (Home)
📈 실시간 차트          (Live Chart)
📝 주문 실행           (Order Entry)
💼 포트폴리오          (Portfolio)
  ├─ 포지션 관리
  ├─ 거래 내역
  └─ 손익 분석
🎯 전략 관리           (Strategies)
  ├─ 전략 목록
  ├─ 전략 생성
  └─ 백테스팅
📊 리포트             (Reports)
⚙️ 설정               (Settings)
───────────────────
ℹ️ 도움말             (Help)
🚪 로그아웃           (Logout)
```

**메뉴 항목 스펙:**
- 높이: 48px
- 패딩: 12px 16px
- 아이콘 + 텍스트 간격: 16px
- Active 상태: 배경 Primary 100, 좌측 Border 4px Primary 500
- Hover: 배경 Gray 100

**축소 버튼:**
- 하단 고정
- 아이콘: `chevron_left` (확장), `chevron_right` (축소)

### 1.5 계좌 요약 카드

**위치:** 메인 콘텐츠 최상단  
**크기:** 전체 너비 × 120px  
**배경:** White, Border Radius 12px, Shadow Level 1

**레이아웃:**

```
┌─────────────────────────────────────────────────────────────┐
│  💰 총 자산          📈 오늘 손익        📊 수익률          │
│  ₩ 50,000,000       +₩ 1,234,567      +15.67%           │
│  Gray 600           Success/Error     Success/Error     │
├─────────────────────────────────────────────────────────────┤
│  💼 평가 금액        🏦 예수금          📍 활성 전략        │
│  ₩ 35,000,000       ₩ 15,000,000      3개                │
└─────────────────────────────────────────────────────────────┘
```

**각 지표:**
- 라벨: Body Small (12px), Gray 600
- 값: Numeric Large (24px), Bold
- 간격: 컬럼 간 32px
- 아이콘: 24px, 좌측 배치

**색상 규칙:**
- 수익: Success (Green)
- 손실: Error (Red)
- 중립: Gray 900

### 1.6 손익 차트 위젯

**위치:** 계좌 요약 카드 하단  
**크기:** 8 컬럼 (66.67% 너비) × 400px  
**배경:** White, Border Radius 12px, Shadow Level 1

**헤더 영역:**
```
[차트 제목: "일일 손익 추이"]  [기간 선택: 1D 7D 1M 3M 1Y] [새로고침]
```
- 제목: H5 (16px), Medium
- 기간 버튼: Label Medium (12px), 간격 8px
- Active 버튼: 배경 Primary 100, 텍스트 Primary 700

**차트 영역:**
- 타입: Line Chart
- 높이: 320px
- X축: 시간 (자동 간격)
- Y축: 금액 (천 단위 표시)
- 라인 색상: Primary 500
- 라인 굵기: 2px
- Fill: Gradient (Primary 500 → Transparent)
- Grid: 점선, Gray 200

**툴팁:**
```
┌──────────────────┐
│ 2025-10-25 14:30 │
│ 손익: +₩ 123,456 │
└──────────────────┘
```
- 배경: rgba(0, 0, 0, 0.8)
- 텍스트: White
- Border Radius: 4px
- 패딩: 8px 12px

### 1.7 시장 지수 위젯

**위치:** 손익 차트 우측  
**크기:** 4 컬럼 (33.33% 너비) × 400px  
**배경:** White, Border Radius 12px, Shadow Level 1

**구성:**
```
[시장 지수]

KOSPI
2,650.43  ▲ +15.23 (+0.58%)

KOSDAQ  
890.12    ▼ -5.47 (-0.61%)

S&P 500
4,350.50  ▲ +12.34 (+0.28%)

NASDAQ
13,500.25 ▲ +89.67 (+0.67%)

─────────────────
업데이트: 14:35:12
```

**각 지수 항목:**
- 지수명: Label Large (14px), Medium
- 현재가: Numeric Medium (18px), Bold
- 변동: Body Small (12px)
  - 상승: Success, ▲ 아이콘
  - 하락: Error, ▼ 아이콘
- 간격: 항목 간 16px

**자동 업데이트:**
- 실시간 (SignalR)
- 변동 시 깜빡임 효과 (0.3s)

### 1.8 보유 포지션 테이블

**위치:** 손익 차트 하단  
**크기:** 전체 너비 × 자동 높이 (최소 400px)  
**배경:** White, Border Radius 12px, Shadow Level 1

**헤더:**
```
[보유 포지션]                    [필터: 전체 | 수익 | 손실] [내보내기]
```

**테이블 컬럼:**
```
| 종목명      | 현재가    | 보유수량 | 평균단가  | 평가금액    | 손익      | 수익률   | 액션     |
|----------|---------|--------|---------|-----------|----------|---------|---------|
| 삼성전자    | 72,500  | 100    | 70,000  | 7,250,000 | +250,000 | +3.57%  | [···]   |
| 카카오      | 48,000  | 50     | 52,000  | 2,400,000 | -200,000 | -7.69%  | [···]   |
```

**컬럼 정렬:**
- 종목명: 좌측 정렬
- 숫자: 우측 정렬
- 액션: 중앙 정렬

**컬럼 스타일:**
- 헤더: 배경 Gray 50, 텍스트 Label Medium, Gray 700
- 행 높이: 56px
- 구분선: 1px solid Gray 200
- Hover: 배경 Gray 100

**손익 색상:**
- 수익: Success Bold
- 손실: Error Bold
- 손익률에 `+` 또는 `-` 표시

**액션 버튼 (···):**
- 클릭 시 드롭다운
  - 상세 보기
  - 청산 주문
  - 차트 보기

**페이지네이션:**
- 하단 중앙
- 10개씩 표시
- `< 1 2 3 ... 10 >`

### 1.11 반응형 디자인

#### 데스크톱 (1280px+)
위 레이아웃 그대로

#### 태블릿 (768px ~ 1279px)
```

- 테이블: 카드 형식으로 변환
```

## 2. 주문 실행 화면

### 2.1 화면 개요

**목적:** 수동 주문 실행 및 관리

**접근 경로:** 사이드바 → 주문 실행

**주요 기능:**
- 종목 검색 및 선택
- 매수/매도 주문 입력
- 주문 검증 및 실행
- 미체결 주문 관리

---

### 2.2 레이아웃 구조

```
┌─────────────────────────────────────────────────────────────┐
│                     [주문 실행]                               │
├─────────────────────────────────────────────────────────────┤
│  [종목 검색]                                                  │
├────────────────────┬────────────────────────────────────────┤
│                    │                                        │
│  [차트 & 호가창]    │     [주문 입력 패널]                    │
│                    │                                        │
│  (좌측 60%)        │     (우측 40%)                         │
│                    │                                        │
├────────────────────┴────────────────────────────────────────┤
│  [미체결 주문 목록]                                           │
└─────────────────────────────────────────────────────────────┘
```

---

### 2.3 종목 검색

**위치:** 최상단  
**높이:** 80px

**구성:**
```
[검색 아이콘] [입력 필드: "종목명 또는 코드 입력"]  [최근 검색] [관심종목]
```

**검색 입력:**
- 너비: 400px
- 자동완성 드롭다운
- 최근 검색 항목 5개 표시

**선택된 종목 정보:**
```
삼성전자 (005930)  72,500원  ▲ +500 (+0.69%)
```
- 종목명: H5 (16px), Bold
- 가격: Numeric Medium (18px), Bold
- 변동: Body Medium, Success/Error

---

### 2.4 차트 & 호가창

**위치:** 좌측 60%

**탭 구조:**
```
[차트] [호가] [체결]
```

#### 차트 탭
- 타입: Candlestick (캔들 차트)
- 높이: 500px
- 인디케이터: 이동평균선 기본 표시
- 줌/팬 가능
- 타임프레임 선택: 1분, 5분, 30분, 1일

#### 호가 탭
```
매도 호가                     매수 호가
────────────────────────────────
72,800  [███████] 3,500주     
72,700  [█████] 2,100주       
72,600  [███] 1,800주         
72,500  [현재가]              
        [███] 1,500주   72,400
        [█████] 2,800주 72,300
        [███████] 4,200주 72,200
```

- 매도호가: Error 계열
- 매수호가: Success 계열
- 바 차트: 거래량 시각화
- 실시간 업데이트

#### 체결 탭
```
시간      가격      체결량    구분
14:35:12  72,500   100주    매수
14:35:10  72,450   200주    매도
14:35:08  72,480   150주    매수
```

- 매수 체결: Success 배경
- 매도 체결: Error 배경
- 자동 스크롤 (최신 항목 상단)

---

### 2.5 주문 입력 패널

**위치:** 우측 40%  
**배경:** White, Border Radius 12px, Shadow Level 2

**탭 전환:**
```
[매수] [매도]
```
- Active 탭: Success (매수), Error (매도)

**입력 필드:**

```

│ 주문 가격                      │

│                              │
│ 주문 수량                      │
│ [100] 주  [+] [-]            │
│                              │
│ 주문 금액                      │
│ 7,250,000원                  │
├──────────────────────────────┤
│ 예상 수수료: 7,250원           │

      [매수 주문 실행]
```

**입력 필드 스펙:**
- 높이: 48px
- 간격: 16px
- 라벨: Label Large, Gray 700

**라디오 버튼:**
- 크기: 20px
- 간격: 24px
- Primary 색상

**수량 입력:**
- Stepper 버튼 (+/-): 32px
- 증가/감소: 10주 단위
- 최소: 1주

**주문 버튼:**
- 높이: 56px (크게)
- 전체 너비
- 매수: Success 배경
- 매도: Error 배경
- 로딩 상태: Spinner 표시
