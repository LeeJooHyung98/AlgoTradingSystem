## 기술 스택 요약

### Backend
- **.NET 8 / C#**: 메인 개발 언어
- **ASP.NET Core**: Web API
- **Blazor Server**: 실시간 대시보드

### Architecture
- **Clean Architecture**: 레이어 분리
- **DDD**: Bounded Context 설계
- **CQRS**: 읽기/쓰기 분리
- **Event Sourcing**: 이벤트 기반 상태 관리

### Database
- **PostgreSQL 17**: 거래 데이터, 사용자 정보
- **TimescaleDB**: 시계열 데이터 (시세)
- **Redis**: 캐싱, 실시간 데이터

### Messaging
- **RabbitMQ**: 이벤트 버스
- **SignalR**: 실시간 통신

### External API
- **키움 OpenAPI**: 한국 증권사 API

### DevOps
- **Azure**: 클라우드 호스팅
- **GitHub Actions**: CI/CD
